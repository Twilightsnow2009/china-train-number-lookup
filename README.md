# china-train-number-lookup
基于2026新版《列车车次编排规定》的纯静态车次查询工具，支持车次解析、字头速查、明暗双主题与全端响应式适配

# 列车车次查询工具 · 2026新版编排

一款零依赖、纯静态的列车车次查询网页工具，依据2026年新版《列车车次编排规定》开发，输入车次即可快速查看用途分类、速度等级、运行范围、实施批次与参考车型等信息。

## ✨ 功能特性

- **精准车次解析**：支持 X/G/T/K/D/C/S/Z/N/V/Y/B/DH/DJ 等全字头车次，以及5位纯数字大宗货运/路用列车查询，自动匹配号段并标注产品类别
- **字头速查表**：按旅客列车、货物列车、路用列车三大分类展示全部字头规则与号段划分，支持分类筛选
- **批次切换说明**：清晰标注第一批、第二批车次实施范围，区分新旧车次含义，避免混淆
- **明暗双主题**：支持深色/浅色模式手动切换，自动跟随系统偏好，本地存储记忆用户选择
- **全端响应式**：完美适配桌面、平板、手机等各类设备，移动端交互专门优化
- **开箱即用**：单 HTML 文件实现全部逻辑，无后端、无依赖，可直接部署到任意静态托管平台

## 📋 数据说明
 
1. 本项目所有字头含义、号段范围、速度等级与实施批次，均依据国铁集团2026年公开的新版《列车车次编排规定》及官方权威访谈整理
