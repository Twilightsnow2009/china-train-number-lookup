列车车次查询

输入车次号，一眼看懂这趟车的 用途、班列编组、运行范围 与 实施批次

列车车次查询是一个依据 2026 年新版《列车车次编排规定》整理的静态查询工具。 输入任意车次号，即可查看该车次的用途 / 产品类别、速度等级、 运行范围与班列编组。新版车次按旅客列车、货物列车、路用列车分类， 构建了“分类清晰、层次分明、直观易记”的编码体系；新旧车次分两批切换。 以 0 开头的车次表示空车回送，0 后面跟的是正式车次（如 0G1 即 G1 的空车底回送）， 车上只有司机与随车机械师，不载客。

常见问题

关于新版车次编排，你可能还想了解

新版列车车次编排有哪些主要变化？
字头重新分配：T、K 字头从普速改为高速动车组，普速特快与快速分别改为 N、V；新增 X 字头（更高速度复兴号）与 DH 字头（货运动车组）；G 字头专指 350 公里级复兴号；C、S 字头收窄适用范围。
0 开头的车次是什么？
0 开头表示空车回送，0 后面跟的是正式车次。例如 0G1 表示 G1 车次的空车底回送，用于动车组出库、回所、转场、热备等，车上只有司机和随车机械师，不载客。
为什么用旧车次查不到了？
新旧车次分两批切换：11 月下旬普速与货运先行，12 月下旬高速与城际跟进。旧字母可能已赋予新含义，建议按新版车次查询，并在 12306 核对到发车站与时刻。
如何判断一趟车可能使用的车型？
本页按字头与速度等级列出可能车型，如 G 字头常见 CR400AF/BF 系列，T 字头常见 CRH380 系列，D 字头为 CR200J 动集，C/S 字头为 CRH6 及 CJ 系列。具体以实际配属为准。
纯数字车次现在代表什么？
1 至 4 位纯数字已不再用于旅客列车（001–298 为厂修客车回送，属特殊回送）；5 位纯数字为大宗直达货物列车（71001–77998 重载、80001–84998 煤炭、85001–85998 石油）或单机、路用、救援等特殊列车。
